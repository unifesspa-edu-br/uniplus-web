Referência visual composta por escopo 1 (primeira entrega estrutural aprovada pelo PO), mais três indicadores quantitativos da Feature Web #1384 / Story Web #1285: Inscrições, Inscritos e Rascunhos. O painel, a identificação do processo, a navegação e a seção Acompanhamento são preservados. Distribuições, situações operacionais, filtros por situação, inscrições nominais, prazos e demais funções ficam fora desta proposta.

Escopo e validação: a primeira entrega estrutural já foi aprovada pelo PO; a apresentação dos três cartões é uma proposta de referência visual para revisão do LT/equipe Web. Todos os números são fictícios. Não há API real, autenticação ou concessão real de acesso. O produto deve reutilizar o Shared UI / Design System, não copiar o HTML deste protótipo.
