# Marca da Unifesspa

`unifesspa-horizontal-extenso.png` é a marca horizontal colorida, com a linha "Universidade Federal do
Sul e Sudeste do Pará", da identidade visual oficial de 2019:
<https://www.unifesspa.edu.br/identidade-visual-da-unifesspa> (Manual de Identidade Visual da Unifesspa).

O arquivo é o PNG oficial (`Marca-Horizontal-Smbolo-Tipografia-001.png`) recortado só na margem branca
excedente e reduzido para 180 px de altura, cerca de três vezes o tamanho impresso (15 mm), para a
impressão a laser.

**Não editar, não redesenhar e não vetorizar** (manual, p. 17). Trocar pelo vetor oficial quando a
Assessoria de Comunicação o fornecer.
